# Архитектура

Next.js обслуживает русскоязычный интерфейс и проксирует REST-запросы в FastAPI. Браузер работает с одним origin. Сессионная cookie хранит случайный токен, а PostgreSQL хранит только его хеш. Данные привязаны к компании из сессии. Видимость сотрудников, задач, смен и заявлений определяется в backend/app/policy.py. HTTP-обработчики используют backend/app/services.py для вычисления показателей, остатков и статусов.

Отпуска и больничные используют одну модель заявления с отдельными типами. Модель сотрудника хранит рабочий профиль, должность и роль. Комментарии и история записываются в журнал событий. Больничные хранятся в приватной таблице PostgreSQL и выдаются как файлы после проверки доступа к заявлению. Внешние модули можно подключать через API, события и новые миграции.

Отчёт по плану использует выбранную группу задач по сроку исполнения. Персональная эффективность из этих данных не вычисляется. Отпуск списывается в календарных днях текущего года. Расписание относит даты к часовому поясу Asia/Almaty.
